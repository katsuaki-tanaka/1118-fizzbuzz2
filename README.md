# FizzBuzz (1〜50) アニメーション Web ページ

1 から 50 までの範囲で FizzBuzz をカード・グリッド形式でカウントアップ・アニメーション表示する Web アプリケーションです。外部ライブラリへの依存がなく、単一の HTML ファイルですぐに動作します。

---

## 📖 FizzBuzz ルール

| 条件 | 表示 | バッジ色 |
| :--- | :--- | :--- |
| **15 の倍数** (3 と 5 の公倍数) | **FizzBuzz** | 🔮 パープルグラデーション |
| **3 の倍数** | **Fizz** | 🔷 青色 |
| **5 の倍数** | **Buzz** | 🔶 オレンジ色 |
| **上記以外** | **数値そのもの** | ⚪ ニュートラルグレー |

---

## 🌟 特徴

- **3段階の本格爆裂演出（Canvas 2D物理エンジン搭載）**:
  1. **① 爆弾チャージ**: マスに赤熱する爆弾（`💣`）が出現し、火花を散らしながら震えて膨張。
  2. **② ドカーン！大爆発**: 全画面 `<canvas>` による火球クラスター（加算合成）・二重衝撃波・重力付き火花・回転して吹き飛ぶ破片・立ち昇る黒煙・カメラシェイク・コミック文字（`BOOM!` / `FIZZ!` / `BUZZ!` / `FIZZBUZZ!!`）が60fpsで炸裂！
  3. **③ 爆煙の中からカード出現**: **爆発した後に**、立ち昇る煙の中から赤熱したカードが飛び出して定着します。
- **Web Audio API 爆発サウンド**: 外部音声ファイル不要のリアルタイム合成による重低音爆発サウンドを搭載（ワンクリックで ON/OFF 切り替え可能）。
- **直感的なカラーリング＆10列コンパクト配置**: 条件ごとに背景色や文字色、爆発の火球カラーが変化し、PC画面で 10列×5行（50枚）が一覧で収まります。
- **コントロール機能**:
  - **爆発カウント開始 / リセット / 爆発音 ON・OFF**
  - **テンポ変更**: 「じっくり (650ms)」「ゆっくり (420ms)」「ふつう (250ms)」「連続爆撃 (120ms)」から選択可能。
  - **進捗表示**: 現在の描画カウント数（`x / 50`）をリアルタイムに表示。
- **完全スタンドアロン**:
  - HTML、CSS、JavaScript を 1 つのファイル（`index.html`）に集約しており、ブラウザで開くだけですぐに動作します。

---

## 🚀 使い方

1. 本リポジトリの `index.html` をお好みのブラウザ（Google Chrome, Edge, Safari など）で直接開きます。
2. 画面上の **「カウント開始 ▶」** ボタンをクリックします。
3. 1 から 50 までが順次アニメーション表示されます。
4. **「リセット ↺」** ボタンをクリックすると、初期状態に戻すことができます。
